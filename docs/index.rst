INTERSECT-DIAL
==============

DIAL is an INTERSECT service for active learning in the context of sequential design. The intention is for cross-domain experiments to be able to craft declarative campaigns which can use DIAL workflows.

This documentation website is intended to target high-level users of INTERSECT-DIAL. Developers should read the README in the `repository <https://github.com/INTERSECT-DIAL/dial>`_ instead.
